# AI-driven Chemical Threat Detection & Evacuation Route Optimization

**Research Internship Project | DRDO (Defence Research & Development Organisation)** *Duration: May 2025 – July 2025*

## 📌 Project Overview
This project focuses on developing an AI-powered system designed to enhance defense capabilities in chemical warfare or industrial accident scenarios. The system detects harmful chemical threats using sensor data, predicts the spread of exposure using simulation models, and calculates the safest evacuation routes to minimize casualties.

## 🚀 Key Features

### 1. Chemical Threat Detection
- Analyzed sensor datasets including gas concentration, temperature, humidity, and wind patterns.
- Implemented Machine Learning models (**Random Forest, Gradient Boosting, SVM**) to classify threat levels.
- Achieved high accuracy in predicting chemical exposure risks.

### 2. Hazard Spread Simulation
- Utilized **Gaussian plume modeling** and diffusion models to simulate chemical spread in real-time.
- Integrated spatial environmental factors such as wind speed, direction, and building layouts to predict risk zones.

### 3. Evacuation Route Optimization
- Constructed weighted graphs representing possible escape paths.
- Applied **Dijkstra’s Algorithm** and **A* Search** to determine the shortest and safest exit routes.
- Visualized evacuation pathways on a map-like interface to support decision-making.

## 🛠️ Technologies Used
- **Languages:** Python
- **Machine Learning:** Scikit-learn, Pandas, NumPy
- **Simulation & Math:** Gaussian Plume Models, Graph Theory
- **Algorithms:** Dijkstra, A* Search
- **Visualization:** Matplotlib, Jupyter Notebooks

## 📊 Key Outcomes
- Designed a functional early warning system to assist emergency response teams.
- Significantly reduced evacuation planning time through algorithmic optimization.
- Demonstrated the practical application of AI in national defense and safety operations.
